# Number AI — проект Android с облачной сборкой APK

Это исходный проект-помощник для тестирования игры «Генератор номеров». Готового APK в архиве нет: его создаёт GitHub Actions после загрузки проекта в репозиторий.

## Как собрать APK только с телефона

1. Скачай и распакуй `NumberAI_Android_GitHub.zip`.
2. Открой https://github.com/ в браузере и войди в аккаунт (или создай его).
3. Создай новый репозиторий, например `NumberAI-Android`. Для простоты можно выбрать **Public**; если выбираешь Private, проверь доступность Actions для репозитория.
4. Загрузи **содержимое папки `NumberAI_Android`** в корень репозитория. Важно: файл `.github/workflows/build-apk.yml` тоже должен попасть в репозиторий. Если мобильный интерфейс GitHub не показывает скрытые файлы/папки, используй загрузку архива через веб-интерфейс, который сохраняет структуру, либо другой способ загрузки файлов.
5. Открой вкладку **Actions**. Выбери **Build Number AI APK** и нажми **Run workflow**. При первом запуске GitHub может попросить включить Actions.
6. Дождись зелёной галочки. Открой завершённый запуск, прокрути до **Artifacts** и скачай `NumberAI-debug-apk`.
7. Распакуй скачанный архив — внутри будет `app-debug.apk`. Открой его на телефоне и разреши установку из этого источника, если Android спросит.

Если сборка красная, открой запуск → шаг, отмеченный красным, и пришли текст ошибки. Не присылай токены или пароли.

## Что умеет этот прототип

- Экран настроек и запуск службы специальных возможностей Android.
- Плавающая панель управления, лимит действий, интервал и кнопка «СТОП ВСЁ».
- Обработка доступного Android текстового содержимого и OCR через ML Kit при поддержке API.
- Локальное сохранение настроек.

## Ограничения — прочитай перед запуском

- Это **не готовый проверенный APK**: облачная сборка ещё должна завершиться успешно, а приложение нужно проверить на устройстве.
- Автоматическая продажа и полноценная навигация по меню игры не реализованы.
- OCR может ошибаться, поэтому нельзя считать защиту редких номеров гарантированной. Сначала тестируй вручную с маленьким лимитом и не оставляй автоматизацию без присмотра.
- Не добавляй в репозиторий пароли, ключи или другие секреты.
